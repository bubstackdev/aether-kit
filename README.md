# Aether-Kit

A Swift package for running open-weight models on-device with Apple's Core AI framework (macOS 27 / iOS 27).
Aether-Kit is a from-scratch re-architecture of [john-rocky/coreai-kit](https://github.com/john-rocky/coreai-kit),
and shares no code with it.

**Status:** design phase. Start with [`docs/DESIGN.md`](docs/DESIGN.md). Experiments that this design depends on run
in the separate `lab` repo, and their results are promoted here by re-implementing them, never by copying code.
