# AetherKit 0.0.4 — experimental developer preview

Draft: not released. The [changelog](../../CHANGELOG.md) lists every change on `main`.

- **API freeze.** The app-facing API is frozen for the rest of 0.0.x: the language facade (`AetherLanguageModel`,
  sessions, streaming and structured output), model preparation and readiness with the catalog entry types, and the
  lifecycle policy and state types. Later 0.0.x releases add to it and never break it, and CI enforces that against a
  committed baseline ([API stability](../api-stability.md)). Enums that can grow are `@nonexhaustive`: switches over
  them outside the package need `@unknown default` (changelog, Breaking).
- **One published sample bundle.** Kit publishes Qwen3-0.6B, converted from `Qwen/Qwen3-0.6B` under Apache-2.0, at
  [`aether-models/aether-kit-qwen3-0.6b`](https://huggingface.co/aether-models/aether-kit-qwen3-0.6b). It distributes
  no other weights.
- **Sample app.** `Examples/SampleApp` downloads that bundle, checks it, chats with it, runs a structured-output request
  and shows its lifecycle, on iOS and on a sandboxed Mac ([sample app](../sample-app.md)).
