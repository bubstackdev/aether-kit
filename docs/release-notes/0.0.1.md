# AetherKit 0.0.1 — experimental developer preview

Released 2026-10-26.

AetherKit is a Swift package for running generative models on Apple Core AI, with model-specific execution recipes for Apple silicon. 0.0.1 is the first tagged preview. Its reference product is Krea 2 Turbo text-to-image; experimental language and MiniMax H3 qualification runtimes ship alongside it. **There is no API compatibility promise in 0.0.x, and no model weights are distributed.**

## Install

```swift
.package(url: "https://github.com/atelier-private-dev/aether-kit", exact: "0.0.1")
```

See the [README](../../README.md) for the Krea and language quick starts.

## Highlights

- **Krea text-to-image end to end:** text encoding, four denoiser segments per Euler step and VAE decoding. Prepared prompts encode once and render many seeds. Sessions support balanced or resident residency, cooperative cancellation and an awaited terminal `unload()`.
- **Measured performance at 512×512, eight steps:**
  - about 4.6 s per repeat image (0.535 s per step)
  - 14.1 s per fresh prompt (balanced) or 5.0 s (resident, about 7.6 GB more GPU memory)

  See the [record](../evidence/krea-residency-load-path-2026-10-26.json).
- **Bounded model verification:** stream hashing no longer keeps whole files in memory. `verify-krea` peaks at 29 MiB instead of about 19.4 GiB, and hashes the six streams concurrently in about 3 s.
- **Language (experimental):** a growable fp16 KV cache, chunked prefill, token streaming that overlaps the next decode step, and explicit `unload()`.
- **H3 (experimental):** BF16 native sessions used to qualify block, chain, outer-phase and linked eight-step provided-conditioning denoising on the GPU.

## Known limitations

- **Single qualified device;** iOS is unqualified.
- **No published Krea bundle specification,** and no hosted assets. You supply your own Core AI exports.
- **Slow first image:** 23–79 s in a new process, mostly first model loads.
- **Krea progress callbacks are synchronous:** a slow observer stalls sampling.
- **No global memory admission** across sessions.
- **Language:** the current export contract reloads the native model every 128 submissions.
- **H3:** qualification sessions only. Whole-run lifecycle is unqualified. A CPU-tested speedup to H3 file verification was held back until H3 assets are regenerated and requalified.
- **No CI;** checks run locally.
