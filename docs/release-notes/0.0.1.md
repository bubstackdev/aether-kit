# AetherKit 0.0.1 — experimental developer preview

Released 2026-10-26.

AetherKit is a Swift package for running generative models on Apple Core AI, with model-specific execution recipes for Apple silicon. 0.0.1 is the first tagged preview. Its reference product is Krea 2 Turbo image generation (text-to-image, reference images and image-to-image refine). Experimental language and MiniMax H3 video-with-audio runtimes ship alongside it, together with verified local asset installation and optional shared resource reservations. **There is no API compatibility promise in 0.0.x, and no model weights are distributed.**

## Install

```swift
.package(url: "https://github.com/atelier-private-dev/aether-kit", exact: "0.0.1")
```

See the [README](../../README.md) for the quick starts.

## Highlights

- **Krea:**
  - text-to-image with prepared prompts
  - reference images through the bundle's vision encoder
  - image-to-image refine, including an off-grid start sigma
  - balanced or resident residency, cooperative cancellation and awaited terminal `unload()`
  - sessions that open from verified `AetherAssets` installations, with optional `KreaResourceAdmission`
- **AetherAssets:** staged, SHA-256-verified, immutable local installations with reader leases and lock-coordinated recovery of abandoned stages.
- **Language (experimental):** a growable fp16 KV cache, chunked prefill, token streaming that overlaps the next decode step, and explicit `unload()`.
- **H3 (experimental):** `H3VideoSession` over native profile stages (prompt conditioner, keyframes, denoising with double-buffered weights, tiled video and fixed-length audio decoders), plus a local tokenizer and checkpoint leases.
- **Bounded, concurrent model verification:** stream hashing keeps memory bounded and hashes Krea streams concurrently, taking about 3 s instead of about 7 s on the reference bundle.

## Known limitations

- **Single qualified device;** iOS is unqualified.
- **No published Krea bundle specification,** and no hosted assets or download transport.
- **Slow first image:** model first-load dominates the first image in a process.
- **Krea progress callbacks are synchronous.**
- **Resource admission reserves caller estimates** rather than enforcing measured footprint, and qualified estimates aren't shipped.
- **Language:** the export contract reloads the native model every 128 submissions.
- **H3:** `H3VideoSession` lacks committed end-to-end graph, trajectory, decoder, lifecycle, memory and media qualification records. The 2026-10-18 prototype-bundle gates are historical, because their assets were lost.
- **CI** needs an equipped macOS 27 runner.

## Compatibility

This is the first tagged release. Expect source-breaking changes in any 0.0.x release.
